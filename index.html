OpenMguesser

Sei dentro una mappa a 360°. Muoviti, cerca indizi, poi indovina dove sei. Gratis, senza account.

Mapillary: gratuita, già configurata. Panoramax: aperta, copertura soprattutto europea. Google: Street View ufficiale, serve la tua chiave API.

Crea una chiave nella Google Cloud Console e abilita Maps JavaScript API (serve la fatturazione attiva; Google offre un credito mensile). Limitala per referrer HTTP al tuo sito. La chiave resta salvata solo nel tuo browser e i costi sono a tuo carico.
